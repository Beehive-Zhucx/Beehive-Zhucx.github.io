这是一次尝试，基于github 搭建开放的博客内容，旨在分享技术，友好互通.

## Quick Start

### Create a new post

``` bash
$ hexo new "My New Post"
```

### Run server

``` bash
$ hexo server
```


### Generate static files

``` bash
$ hexo generate
```


### Deploy to remote sites

``` bash
$ hexo deploy
```
